# 梦核游乐园 · 点击探索

一款纯原生 HTML / CSS / JavaScript 的梦核风格点击解谜小游戏。无框架、无第三方库，背景音乐与音效均由 Web Audio API 实时合成。

```
├── index.html          # 页面入口（HTML 结构）
├── style.css           # 样式表
├── game.js             # 游戏逻辑（顶部集中管理图片路径）
├── Dreamcore场景/      # 场景图片（10 张 JPG）
```

## 本地运行

**方式一：直接打开**

双击 `index.html`（或用浏览器打开即可）。

**方式二：本地服务器（推荐）**

个别浏览器在 `file://` 协议下可能有资源加载限制，建议用本地服务器：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000

# 或 Node.js
npx serve
```

> 注意：受浏览器自动播放策略限制，背景音乐需要**首次点击画面**后才会启动。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，把以下文件/目录完整上传（保持目录层级不变）：
   - `index.html`
   - `style.css`
   - `game.js`
   - `Dreamcore场景/`（整个图片目录）
2. 仓库 **Settings → Pages**，把 Source 设为 `main` 分支、根目录 `/ (root)`，保存。
3. 等待构建完成，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

> 若部署到子路径（即 `<用户名>.github.io/<仓库名>/`），本游戏使用的都是**相对路径**，无需任何改动即可正常工作。

## 图片路径说明

所有图片均使用**相对路径**，集中定义在 `game.js` 顶部的 `IMAGE_PATHS` 对象中：

```js
const IMAGE_PATHS = {
  start:           "Dreamcore场景/开局界面.jpg",
  vendingMachine:  "Dreamcore场景/游乐园售货机.jpg",
  // ...其余图片
};
```

路径相对 `index.html` 解析。如需更换或移动图片，只需修改 `IMAGE_PATHS` 中对应的值即可，无需改动游戏逻辑。

## 注意事项（中文路径与大小写）

- 图片路径与文件名包含**中文字符**。GitHub Pages 按 UTF-8 提供文件，现代浏览器可正常访问中文路径。
- GitHub Pages 的服务器运行在 Linux 上，**区分大小写**。请务必保证代码中的路径大小写与实际文件名完全一致。
- 若出现「图片加载失败」，请依次核对：
  1. 文件名大小写是否与 `game.js` 完全一致；
  2. 中文字符是否一致（如 `池核系列`、`结局` 等目录名）；
  3. 目录层级是否正确（图片需位于 `Dreamcore场景/` 下对应子目录）。

## 附注

- `梦核游乐园.html` 是最初的单文件版本（图片以内嵌 base64 形式存在），仅供备份参考，部署时无需上传。
- 游戏玩法与剧情未做任何改动，仅将图片从内嵌 base64 拆分成了独立文件并改用相对路径。
